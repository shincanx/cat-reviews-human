A deterministic Python program that writes one funny one-star review written by a house cat about the human it lives with — a single line of at most 200 characters — to /output/entry.txt. The review: the human bought a $400 cat bed and got offended when the cat slept in the box, and the cat, who pays no rent, is somehow the disappointment.

## Run it

```sh
python3 main.py
```
